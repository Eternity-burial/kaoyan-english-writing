### 2. 视频字幕与逐字文稿

每节课程均提供两套格式：
- **`.srt` 文件**：包含毫秒级对齐时间戳，若将对应视频下载到同目录下，PotPlayer / VLC / IINA 等播放器可自动挂载字幕。
- **`_逐字文稿.md` 文件**：按每 2 分钟时间轴自动分块排版的高信噪比纯文本逐字稿，适合在 VS Code、Obsidian 或 GitHub 直接阅读速查。
